## Import

```tsx
import { Input } from "@florexlabs/ui";
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `placeholder` | `string` | — | Placeholder text |
| `type` | `string` | `"text"` | Native input type, including `date`, `time`, and `datetime-local` |
| `disabled` | `boolean` | `false` | Disabled state |
| `className` | `string` | — | Additional classes |

## Date and time

Use native pickers for scheduled work. Florex UI keeps their dark theme, typography, focus ring, and calendar trigger while the browser preserves its accessible local picker.

```tsx
<Label htmlFor="publish-at">Publish at</Label>
<Input id="publish-at" type="datetime-local" min="2026-10-10T09:00" />
```

`datetime-local` does not contain a timezone. Store the timezone separately when the schedule is for another region.
